# EchoForge 0.4.0

Dictation can now be rewritten into a style you choose - or into an instruction you
write yourself - without leaving your Mac. It is off by default, and when it is on, it
can only improve a transcript or leave it alone.

## Style rewriting

There is a new **Style** tab in Settings. Turn on *Rewrite dictation with a style* and
what you dictate is passed through Apple's on-device language model before it lands in
whatever you were typing in.

Six styles ship with it:

- **Grammar & Polishing** - fixes grammar and punctuation, keeps your wording.
- **Formal Business** - rewrites it as professional written correspondence.
- **Concise Summary** - cuts it down to the essential points.
- **Bullet Points** - reshapes it into a bulleted list.
- **Casual Chat** - relaxes it into everyday conversational writing.
- **Custom Prompt** - rewrites it with an instruction you write yourself, in your own
  words. The same safety checks apply to your prompt as to the built-in styles.

**Try it** in the Style tab runs a sample through the style you picked, using exactly
the same path dictation uses, so you can see what a style does before you rely on it.

### It runs on this Mac

Rewriting uses Apple Intelligence's on-device model, not a hosted service. Dictation is
the most private thing this app touches, so nothing about it is sent anywhere - the same
promise the speech engines already make.

That means it needs **macOS 26 or later on a Mac that supports Apple Intelligence**, with
Apple Intelligence switched on in System Settings. On any other Mac the Style tab says so
plainly and everything else works exactly as before. Rewriting is never a prerequisite for
dictating.

### What stops it going wrong

A language model asked to restyle speech will occasionally translate it, change an amount
or a date, answer the text instead of rewriting it, or obey an instruction that was spoken
into the microphone. You would not see any of that happen - the text is already on its way
into another application.

So the app does not rely on the model behaving. Every rewrite is compared against the
transcript it came from and discarded if it changed the script, invented or altered a
number, dropped a currency or percent sign, lost a word from your personal terms
dictionary, came back at an implausible length, or started addressing you instead of
rewriting. The rule underneath all of it: **a style may leave something out, but nothing
may be invented.**

Rewriting also has a deadline that scales with length and caps at 12 seconds. If the model
is slow, unavailable, or its answer is refused, your transcript is used exactly as
transcribed - the same text 0.3.1 would have given you.

### Your original words are kept

Every recording keeps what the engine actually heard. Open a row in the history and choose
**Show original** to read or copy it. That applies to any post-processing change, not only
a rewrite - the terms dictionary and CJK spacing count too.

## Everything else

Transcription, engines, the personal terms dictionary and CJK spacing are unchanged, and
they do not depend on rewriting in any way. The release packaging work that made 0.3.1
launchable is carried forward: this build is produced by `Scripts/build_release.sh` and was
published only after `Scripts/verify_release_package.sh` checked every embedded library's
signature and `@rpath` dependency and **started the app**.

If you are on 0.3.1, this is a straight upgrade. If you are still on 0.3.0, that build
could not open on any Mac - install this one instead.

## Installing this build

This release is **not signed with an Apple Developer ID and not notarized**, so macOS
will refuse to open it on the first try - typically "the app is damaged and can't be
opened", or "Apple could not verify EchoForge is free of malware". Nothing is wrong with
the download; macOS simply cannot check who built it.

1. Open `EchoForge.dmg` and drag `EchoForge.app` into `Applications`.
   Do not run it from the mounted disk image.
2. Then do **one** of the following, once:
   - Right-click (or Control-click) the app in `Applications`, choose **Open**, and click
     **Open** in the dialog; or
   - run `xattr -d com.apple.quarantine /Applications/EchoForge.app` in Terminal
     (adjust the path if you installed it elsewhere).

Replacing an existing install keeps your recordings, personal terms and downloaded models.
Because these builds are unsigned, macOS treats each one as a new app for permission
purposes, so it will ask for Microphone and Accessibility again - and if a stale
**EchoForge** entry is already listed under **Privacy & Security → Accessibility**, remove
it with the minus button and add the new app back.

This build ships with SenseVoice-Small on board, so it can dictate as soon as it is
installed.
