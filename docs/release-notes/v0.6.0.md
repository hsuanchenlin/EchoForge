# EchoForge 0.6.0

**The download is now about 11 MB instead of 222 MB**, and the installed app is
21 MB instead of 250 MB. Every release from 0.3.0 to 0.5.2 carried one speech
model inside the app bundle - SenseVoice-Small, 229 MB of the 250 MB app - and
almost every user paid for it twice. Models live in
`~/Library/Application Support/`, outside the bundle, and an update replaces only
the app, so anyone who already had the model downloaded it, verified it, mounted
it and copied it into the new build, and then never read a byte of it.

From this release the app is **thin**: it ships no model weights, and the model
you choose is fetched separately, on demand, from this repository - checksummed
before a single file reaches your model cache.

Nothing about how EchoForge transcribes has changed. Transcription, style
rewriting, the Ask panel and screen queries all still run entirely on this Mac.

## Your existing models are kept

This is the part worth saying plainly: **updating does not cost you a download.**

| If you are | What happens |
| --- | --- |
| Updating and already have a model | You keep it. The thin app finds it exactly where it always was and behaves identically. Nothing is downloaded. |
| Updating after deleting your model cache | You get the same model picker a fresh install sees, and choose again. |
| Installing fresh | You pick a model in onboarding and it downloads once. |
| Still running a 0.5.x build | Its bundled copy still installs from its own bundle, unchanged. |

Recordings, personal terms, voice snippets and settings are untouched either way.

## Choosing your model, locally

The first-run screen already asked which model you wanted; it now also owns
getting it. Downloads are **on demand and local to your machine** - nothing is
pre-fetched, nothing is chosen for you, and an engine you never pick is never
downloaded.

For **SenseVoice-Small** those bytes now arrive as a **model pack**: one verified
archive published as a release asset of this repository, listed inside the app
with its exact size and SHA-256. The app refuses any pack whose URL is not HTTPS
on a GitHub release host under this repository, and discards the whole download if
the digest does not match rather than letting a partial or wrong model reach the
cache. An installed pack is indistinguishable from a finished download, so
Settings' badges, deleting the cache, and re-downloading all work exactly as
before.

Every other engine - the Whisper models and Paraformer-large - downloads its
weights the way it always has. A pack is per-engine and opt-in by publication, not
a new requirement.

Details, including what is published and why only one model is packaged this way:
[docs/model-packs.md](https://github.com/hsuanchenlin/EchoForge/blob/master/docs/model-packs.md).

## Downloads that survive a bad connection

The same machinery now carries both app updates and model packs, so both got the
progress reporting the updater gained in 0.5.2 and the **resume** it did not have:

- **Real numbers.** Progress is reported in bytes - "43 MB of 209 MB" - not a
  fraction that sat at 0% for everything from an unanswered request to the first
  megabyte. Speed and time remaining are shown while bytes are moving.
- **Resume.** A transfer that fails at 95% costs one press, not the whole download
  again. The partial file is kept and the next attempt asks the server to continue
  from where it stopped, refusing to append if the server answers with anything
  other than the same file.
- **Checksums.** App releases publish a `.sha256` sidecar and the updater checks
  it; a sidecar that exists and does not match fails the install. Model packs
  carry their digest in the app itself and are checked the same way.
- **A stall is still ended** after 30 seconds of complete silence, and **Cancel**
  and **Retry** are still there. The watchdog measures silence, not speed - a slow
  link is a normal way to fetch 209 MB and must be allowed to finish.

A partial download survives a failed or cancelled transfer. It never survives a
failed verification.

## What has not changed

**EchoForge still never checks for updates on its own.** There is no launch-time
check, no background check and nothing phoning home. Checking, downloading and
installing remain three separate things you press.

**There is no cloud or API transcription in this release, and none is included.**
Every engine EchoForge offers runs on your Mac. No audio, transcript, screenshot
or text is sent to any server, and there is no setting, key or account that would
enable one. The only network traffic the app makes is fetching the model you asked
for and the update you asked for, both from this repository's GitHub releases.

## Upgrading

Install over your existing copy. This build is produced by
`Scripts/build_release.sh` and was published only after
`Scripts/verify_release_package.sh` checked every embedded library's signature and
`@rpath` dependency and **started the app**.

## Installing this build

This release is **not signed with an Apple Developer ID and not notarized**, so
macOS will refuse to open it on the first try - typically "the app is damaged and
can't be opened", or "Apple could not verify EchoForge is free of malware".
Nothing is wrong with the download; macOS simply cannot check who built it.

1. Open `EchoForge.dmg` and drag `EchoForge.app` into `Applications`.
   Do not run it from the mounted disk image.
2. Then do **one** of the following, once:
   - Right-click (or Control-click) the app in `Applications`, choose **Open**, and
     click **Open** in the dialog; or
   - run `xattr -d com.apple.quarantine /Applications/EchoForge.app` in Terminal
     (adjust the path if you installed it elsewhere).

Replacing an existing install keeps your recordings, personal terms, snippets and
downloaded models. Because these builds are unsigned, macOS treats each one as a
new app for permission purposes, so it will ask for Microphone and Accessibility
again - and if a stale **EchoForge** entry is already listed under **Privacy &
Security → Accessibility**, remove it with the minus button and add the new app
back.

Unlike 0.5.2, this build does **not** include a speech model. A brand-new install
picks one on the first-run screen and downloads it once; an existing install keeps
the one it already has.

Full instructions, including how to use the Chinese engines and the basics of
recording:
[docs/install.md](https://github.com/hsuanchenlin/EchoForge/blob/master/docs/install.md).
