# EchoForge 0.3.0

Dictate the moment you install it, and never wait on a model again.

## Ready to dictate out of the box

This build **ships with SenseVoice-Small already included**. A fresh install can dictate
straight away - no download, no waiting, nothing to choose first. The model handles
Mandarin, Cantonese, English, Japanese and Korean, and it punctuates.

It is installed into the same place a downloaded model goes, so nothing about it is a
special case: Settings shows it with its usual "Downloaded and ready" badge, and if you
delete it, EchoForge downloads it again exactly as before. A model you had already
downloaded yourself is never replaced by the included copy.

SenseVoiceSmall is by FunASR / FunAudioLLM and is included here under the FunASR Model
Open Source License v1.1, which requires that it keep its name and its credit. Its model
card, licence and CoreML conversion are linked in Settings next to the engine, and in
[docs/speech-model-attribution.md](https://github.com/hsuanchenlin/EchoForge/blob/master/docs/speech-model-attribution.md).

## Choosing a model no longer stops you working

Picking a new engine used to cost you everything else. The download and the one-time
Neural Engine preparation ran while dictation simply failed with "No transcription engine
is set up", and a full-window overlay covered your history so it could not be read,
searched or played.

Now:

- **Your history stays open the whole time.** No overlay, no dimmed window. Scroll,
  search, play back and copy while a model downloads.
- **Dictation keeps working.** EchoForge carries on with the model you were already using
  - or the included one on a new install - and switches to the model you chose the moment
  it is ready. You do not have to ask twice.
- **Your choice stays your choice.** What Settings shows as selected is what you picked,
  even while something else is doing the transcribing. Nothing is silently swapped
  underneath you, and quitting part-way through a download no longer undoes the selection
  that started it.
- **Dictation is only disabled when there is genuinely nothing to dictate with**, and then
  it says so and offers to try again.

## Progress that means something

Downloads show a real percentage. The Neural Engine preparation that follows shows
**"Preparing model…"** with an indeterminate bar instead - that step publishes no progress
of its own, and a bar frozen at a number would just look like a hang. Transcription
progress and model progress are now separate, because they overlap.

## Settings → About, and updating from inside the app

A new **About** pane shows the version, build number and identifier this copy reports - the
answer to "which build am I actually running".

It is also the only place that offers to update, and it never acts on its own. There is no
background check and nothing installs automatically: checking, downloading and installing
are three separate things you ask for, and you see the release notes and download size
before anything is fetched.

When you do take an update, EchoForge downloads the DMG from this repository's GitHub
releases and **only** from there, then checks that what arrived really is EchoForge, really
is the version it offered, and passes signature verification - before it replaces anything.
Anything that does not check out is discarded with a reason rather than installed.

Because these builds are signed ad-hoc rather than with an Apple Developer ID, that
signature check proves the download was not modified after it was built, not who built it.
The About pane says so plainly. You can always skip the in-app path and install the DMG by
hand instead.

## Everything else is unchanged

The same engines, first-run flow, permissions and shortcuts as 0.2.2. Both Chinese engines
still write Simplified Chinese (簡體字) and EchoForge still does not convert it to
Traditional (繁體字). Paraformer-large (zh) is still an optional download.

## Requirements

- Apple Silicon Mac (M1 or newer)
- macOS 14 (Sonoma) or later

## Installing this build

This release is **not signed with an Apple Developer ID and not notarized**, so macOS
will refuse to open it on the first try - typically "the app is damaged and can't be
opened", or "Apple could not verify EchoForge is free of malware". Nothing is wrong with
the download; macOS simply cannot check who built it.

1. Open `EchoForge.dmg` and drag `EchoForge.app` into `Applications`.
   Do not run it from the mounted disk image.
2. Then do **one** of the following, once:
   - Right-click (or Control-click) the app in `Applications`, choose **Open**, and click
     **Open** in the dialog; or
   - run `xattr -d com.apple.quarantine /Applications/EchoForge.app` in Terminal
     (adjust the path if you installed it elsewhere).

Upgrading from 0.2.x is a straight replace over the old app. Your recordings, personal
terms and downloaded models are kept. Because these builds are unsigned, macOS treats each
one as a new app for permission purposes, so it will ask for Microphone and Accessibility
again - and if a stale **EchoForge** entry is already listed under **Privacy & Security →
Accessibility**, remove it with the minus button and add the new app back.

This build is larger than previous ones because the speech model travels with it.

Full instructions, including how to use the Chinese engines and the basics of recording:
[docs/install.md](https://github.com/hsuanchenlin/EchoForge/blob/master/docs/install.md).
