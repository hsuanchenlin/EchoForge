# EchoForge 0.2.1

A fix for the permission screen that would not go away.

## Accessibility permission is picked up automatically

Granting **Accessibility** access is the one permission you give EchoForge entirely in
System Settings rather than in a dialog the app puts up. Until now, coming back to
EchoForge afterwards often left the setup screen still insisting the permission was
missing, and the only way through was to quit and reopen the app.

That is fixed. Enable EchoForge under **System Settings → Privacy & Security →
Accessibility**, switch back to the app, and the row flips to granted on its own -
usually the moment you grant it, at the latest when EchoForge comes back to the front.
Once Microphone and Accessibility are both granted the app moves on to the normal window
by itself. **No restart needed.**

The same applies later on: if pasting stops working because the grant was removed, the
app notices that too.

Nothing else changed - the same engines, models, first-run flow and permission
requirements as 0.2.0. Microphone and Accessibility are still the two permissions
EchoForge needs; Input Monitoring is still asked for only if you bind recording to a
single modifier key such as Right ⌥.

## Requirements

- Apple Silicon Mac (M1 or newer)
- macOS 14 (Sonoma) or later

## Installing this build

This release is **not signed with an Apple Developer ID and not notarized**, so macOS
will refuse to open it on the first try - typically "the app is damaged and can't be
opened", or "Apple could not verify EchoForge is free of malware". Nothing is wrong with
the download; macOS simply cannot check who built it.

1. Open `EchoForge.dmg` and drag `EchoForge.app` into `Applications`.
   Do not run it from the mounted disk image.
2. Then do **one** of the following, once:
   - Right-click (or Control-click) the app in `Applications`, choose **Open**, and click
     **Open** in the dialog; or
   - run `xattr -d com.apple.quarantine /Applications/EchoForge.app` in Terminal
     (adjust the path if you installed it elsewhere).

Upgrading from 0.2.0 is a straight replace over the old app. Your recordings, personal
terms and downloaded models are kept. Because these builds are unsigned, macOS treats
each one as a new app for permission purposes, so it will ask for Microphone and
Accessibility again - and if a stale **EchoForge** entry is already listed under
**Privacy & Security → Accessibility**, remove it with the minus button and add the new
app back.

Full instructions, including how to use the Chinese engines and the basics of recording:
[docs/install.md](https://github.com/hsuanchenlin/OpenSuperWhisper/blob/master/docs/install.md).
