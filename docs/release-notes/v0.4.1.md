# EchoForge 0.4.1

**Style rewriting now works when you dictate in Chinese.** In 0.4.0 it did not: you could
pick a style, dictate Mandarin, and get back exactly what you said. This release fixes
that. Everything else - transcription, engines, the personal terms dictionary, CJK
spacing - is unchanged.

## What was wrong

The style instructions and the rules the app sends with them were written only in English.
Asked in English, Apple's on-device model answers in English - so "Formal Business"
translated Mandarin dictation into English on every run, and "Casual Chat" on most.

Nothing wrong ever reached the text you were typing into: the safety check that compares a
rewrite against the transcript saw the script change and threw the answer away, exactly as
it is meant to. But a discarded rewrite is an unrewritten transcript, and from the outside
that is the feature simply not working in Chinese.

## What changed

- **Every style is now written in three languages** - English, Traditional Chinese and
  Simplified Chinese - along with the rules and the prompt's own heading. Asked in Chinese,
  all six styles come back in Chinese.
- **The language is picked from what you actually said**, not from the language setting.
  English spoken with the dictation language left on Chinese stays English; the setting
  only breaks ties.
- **Traditional and Simplified are kept apart.** The instruction's own script decides the
  rewrite's, so a Traditional instruction quietly converted Simplified dictation - often
  only half of it. The app now matches the instruction to your transcript, and the safety
  check rejects a rewrite that introduces characters exclusive to the other variant,
  whatever the style.
- **The Chinese polishing style knows Chinese filler.** It names 那個 / 就是 / 然後 / 嗯 /
  呃 rather than translating "um", and asks for full-width punctuation and your own
  sentence breaks.
- **A custom prompt is wrapped, never edited.** The Style pane is in English, so people
  who dictate Chinese write their prompt in English; your words are passed through
  untouched and the language is handled around them.

The rule underneath rewriting is unchanged and still enforced the same way: **a style may
leave something out, but nothing may be invented.** If the model is slow, unavailable, or
its answer is refused, you get your transcript exactly as it was transcribed.

## Upgrading

If you are on 0.4.0, this is a straight upgrade and worth taking if you dictate any
Chinese. If you dictate only in English, 0.4.0 already behaves the way this release does.

Rewriting still needs **macOS 26 or later on a Mac that supports Apple Intelligence**, with
Apple Intelligence switched on, and it is still off until you turn it on in the **Style**
tab. On any other Mac the Style tab says so and everything else works as before.

## Installing this build

This release is **not signed with an Apple Developer ID and not notarized**, so macOS
will refuse to open it on the first try - typically "the app is damaged and can't be
opened", or "Apple could not verify EchoForge is free of malware". Nothing is wrong with
the download; macOS simply cannot check who built it.

1. Open `EchoForge.dmg` and drag `EchoForge.app` into `Applications`.
   Do not run it from the mounted disk image.
2. Then do **one** of the following, once:
   - Right-click (or Control-click) the app in `Applications`, choose **Open**, and click
     **Open** in the dialog; or
   - run `xattr -d com.apple.quarantine /Applications/EchoForge.app` in Terminal
     (adjust the path if you installed it elsewhere).

Replacing an existing install keeps your recordings, personal terms and downloaded models.
Because these builds are unsigned, macOS treats each one as a new app for permission
purposes, so it will ask for Microphone and Accessibility again - and if a stale
**EchoForge** entry is already listed under **Privacy & Security → Accessibility**, remove
it with the minus button and add the new app back.

This build ships with SenseVoice-Small on board, so it can dictate as soon as it is
installed. See the [0.4.0 notes](v0.4.0.md) for everything style rewriting does.

Full instructions, including how to use the Chinese engines and the basics of recording:
[docs/install.md](https://github.com/hsuanchenlin/EchoForge/blob/master/docs/install.md).
